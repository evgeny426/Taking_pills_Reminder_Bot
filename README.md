# 💊 ТаблеткоБот — Telegram-бот для напоминания о приёме лекарств  

Бот помогает не забывать принимать таблетки три раза в день в заданное время (07:00, 15:00, 23:00). Отправляет напоминание с кнопкой для подтверждения приёма.  

## 🛠 Технологии  
- Python 3  
- Библиотека `pyTelegramBotAPI`  
- Встроенные модули: `datetime`, `time`, `threading`  

## ⚙️ Установка и запуск  
1. Установите зависимости: 

   pip install pyTelegramBotAPI
2. Создайте бота в Telegram через @BotFather и получите токен.

3. Вставьте токен в код:

   bot = telebot.TeleBot("ВАШ_ТОКЕН")  # Замените на токен от BotFather
4. Запустите бота:

   python bot.py
   
## 📋 Функционал
Автонапоминания в 07:00, 15:00 и 23:00.

Интерактивная кнопка для подтверждения приёма.

Ответ бота с точным временем приёма таблетки.

## 📝 Пример работы
Пользователь запускает бота командой /start.

👤: /start  
🤖: Привет! Я чат-бот! Я слежу, чтобы ты не забывал(а) принимать таблетку три раза в сутки, в одно и то же время.  
В указанное время бот присылает напоминание:

🤖: Напоминание — прими таблетку! Сейчас 07:00.  
[Кнопка: "Я принял(а) таблетку!"]  
После нажатия кнопки:

🤖: Таблетка была принята в 07:00!
